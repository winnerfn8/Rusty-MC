    Architecture: feature → files → checks

    The 40 areas changed most often in the 30 days to 2026-10-23 (commits on main touching the area; game.rs is counted only for the game loop because nearly every gameplay change touches it). The crate map, how Game is organised and how to build and test are in AGENTS.md.

    Paths: L/ = crates/horizon-client/src/, G/ = crates/horizon-client/src/game/, W/ = crates/horizon-world/src/, K/ = crates/horizon-client-core/src/, C/ = crates/horizon-command/src/, I/ = crates/horizon-items/src/, R/ = crates/horizon-client-render/src/, N/ = crates/horizon-client-input/src/. Checks: a bare name is a harness (python3 tools/parity.py <name>, script tools/test_<name>_parity.py); lan_e2e <check> is python3 tools/lan_e2e.py --check <check>.

    For the full set of harnesses a file can affect, ask the runner: printf '%s\n' <paths> > /tmp/p.txt && python3 tools/parity.py --changed-files /tmp/p.txt --list. Any file of the game binary (game.rs, game/) selects the ~25 harnesses that run the binary; a client lib file selects ~103.
